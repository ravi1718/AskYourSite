# Cal.com Integration

> **Important:** The Cal.com integration is currently in development and not yet available. We'll notify you when it launches.

---

## What's Coming

[Cal.com](https://cal.com) is the open-source alternative to Calendly. The AskYourSite Cal.com integration will let visitors book meetings directly through your AI assistant — just like the [Calendly integration](/docs/integrations/calendly), but for Cal.com users.

## Planned Features

- Connect your Cal.com account via OAuth
- Select which event types to offer per assistant
- Visitors book meetings inline in the chat widget
- No redirect required — seamless booking experience

---

## In the Meantime

If you need meeting booking today, use the [Calendly integration](/docs/integrations/calendly) — it's fully functional and available now.
